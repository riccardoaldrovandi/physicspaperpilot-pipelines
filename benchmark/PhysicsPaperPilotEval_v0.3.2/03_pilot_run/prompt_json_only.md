# Prompt per la pipeline che parte dal JSON — PhysicsPaperPilot

Pipeline B2 (e terzo esperimento: lettore fisso sui JSON di più summarizer). Testo trascritto alla lettera dalla
sezione 11 di `integrazione_pipeline_gold_benchmark.docx.pdf`. Il lettore riceve solo il JSON prodotto dalla pipeline
(prompt v2.1), mai il PDF né la answer key. Una domanda per chiamata.

```text
You are a scientific question-answering system. Your task is to answer questions using ONLY the structured JSON representation of a scientific paper supplied in the input.

INPUTS:
1. PAPER_JSON: the structured JSON generated by the existing paper-understanding pipeline.
2. PAPER_ID: the arXiv identifier of the paper.
3. QUESTION: one benchmark question, including its question_id and options when it is multiple choice.

STRICT RULES:
- Use only information explicitly present in PAPER_JSON. Do not use the original PDF, external sources, or background knowledge.
- Do not fill gaps by inference. Do not invent values, units, equations, conditions, section names, figure numbers, or conclusions.
- If the required information is not recoverable from PAPER_JSON, set answer to exactly: NOT RECOVERABLE FROM STRUCTURED SUMMARY and set abstained to true.
- Preserve numerical values, signs, exponents, symbols and units exactly as represented in PAPER_JSON.
- For a multiple-choice question, put the selected option letter in mcq_choice and explain it briefly in answer.
- evidence_fields must contain the exact JSON paths that directly support the answer (for example: methodology.approach, data_and_setup.simulations_or_experiments, key_results[0].value). Do not cite a path that does not exist.
- cited_evidence must contain only original paper section headings explicitly preserved in PAPER_JSON. Do not infer a section heading from a JSON field name. If no original heading is present, return an empty list.
- Keep the answer concise but include all information needed to answer the question.

OUTPUT:
Return only one valid JSON object, with exactly this structure:
{
  "paper_id": "<arxiv_id>",
  "answers": [
    {
      "question_id": "<question_id>",
      "answer": "<answer or NOT RECOVERABLE FROM STRUCTURED SUMMARY>",
      "mcq_choice": "<A|B|C|D or empty string>",
      "evidence_fields": ["<exact JSON path>"],
      "cited_evidence": ["<exact original paper section heading>"],
      "abstained": false
    }
  ]
}

PAPER_ID:
[INSERT PAPER ID]

PAPER_JSON:
[INSERT THE COMPLETE STRUCTURED JSON]

QUESTION:
[INSERT QUESTION OBJECT FROM questions_public.csv]
```

## Inserimento nel CSV

- `answer` → `model_answer`; `mcq_choice` → `mcq_choice`; `cited_evidence` → `cited_evidence` (separate da `;`).
- `evidence_fields` e `abstained` in un file supplementare: lo script v0.3.1 non li valuta.
